# Mémoire Claude — Nextcloud & homelab

Ce dossier permet de **reprendre le projet si les sessions Claude Code sont perdues**. Le dépôt est public : les adresses
internes, comptes et e-mails ont été masqués et **aucun secret** n'y figure (les mots de passe sont dans un gestionnaire
de mots de passe, jamais dans git).

- `HANDOFF-nextcloud-homelab.md` : document de reprise du projet (état au 2026-09-26, architecture, exploitation, pièges, reste à faire, prompt d'amorçage).
- `memoire/` : notes mémoire Claude relatives au projet (décisions, pièges, état).

## Restaurer
1. Ouvrir Claude Code dans le dossier du projet (crée `~/.claude/projects/<dossier>/`).
2. Copier `memoire/*.md` dans `~/.claude/projects/<dossier>/memory/`, puis créer un `MEMORY.md` d'index.
3. Coller le prompt d'amorçage du document de reprise (§7), s'il existe.

Les transcripts bruts des conversations ne sont volontairement pas versionnés (ils contiennent des mots de passe tapés en clair).
